# Shared project instructions

Read and follow `CLAUDE.md` in this directory before working on the project.
It is the shared source of project guidance for Claude and Codex.
Follow its scoped-instruction lookup when entering a new subtree, including
`writing/CLAUDE.md` when working on the manuscript, figures for the report or
any longer prose.
Package skills are shared through `.agents/skills/`, linked to `.claude/skills/`;
read the relevant skill before package-specific work (if a link is missing, read
`.claude/skills/<name>/SKILL.md` directly).
